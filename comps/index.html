Direction C — The Seal · round one

Four ways to build the same idea.

Same palette, same type, same copy, same content. Only the composition changes, so the comparison is about layout and weight — nothing else. Open each, then tell me which one to push.

01

Ceremony

Symmetric and seal-led. The crest is large and centred, everything hangs beneath it. Most formal, easiest sell to a board.

 View 02

Editorial

Asymmetric and type-led. Headline carries the page, crest sits beside it. Reads like a magazine rather than a prospectus.

 View 03

Frame

The shield’s 2×2 becomes literal page structure. Biggest type, smallest crest. Most graphic, furthest from a default school site.

 View 04

Ink

Inverted hero — gold on deep purple-black, then paper below. Tests whether the crest wants a dark ground.
